本ドキュメントは、アプリ内の全画面とその役割を一覧で整理する。

画面単位での責務を明確にし、設計・実装・テストの基準とする。

## 4. MVPスコープ

以下はMVPでは実装しない：

- 専用のプラン編集画面
- 備蓄商品編集画面
- 備え見直し専用画面

これらは既存画面で代替する。

### 4.1 補足：備えプラン編集機能について

- 備えプラン編集機能は当初MVP対象外として整理していた追加機能として、UI-007 備えプラン詳細画面に限定的に実装する
- 編集可能項目は `プラン名 / 人数 / 日数` に限定する
- 人数・日数変更時の再計算対象は `商品の数量のみ` とする

---

## 5. 補足

- 商品購入は外部サイト遷移で行う
- 通知メールは備蓄品一覧画面へ遷移する
- 認証必須画面は未ログイン時ログイン画面へリダイレクトする
- 備えプラン編集は専用画面を作らず、UI-007 備えプラン詳細画面に追加機能として限定実装する
- 備蓄品一覧画面では、登録済み備蓄商品の `数量 / 単価 / 賞味期限` のみ編集可能とする
