- 区分: XSS対策
- 確認対象:
  - `PATCH /api/family-members/[id]`
  - `PUT /api/family-members/[id]/allergens`
  - `POST /api/stock-items`
- 確認内容: 入力値がそのまま危険なHTMLとして扱われないか
- 実施結果: 要追加確認
- 問題内容: API側では文字列を保存しうるが、今回確認した範囲では危険なHTML描画処理は未確認
- 対応要否: 今回は対応しない
- 対応方針: API単体ではXSS確定不可。表示側で `dangerouslySetInnerHTML` を使っていないか別確認対象とする

- 実施結果: 500 Internal Server Error
- 問題内容: 入力不正であれば400 Bad Requestの方が自然
- 対応要否: 今回は対応しない
- 理由: 他人データ参照防止や削除防止などの重大論点は問題なく、MVPでは優先度を下げる
- 対応方針: 改善余地として実施記録に残す

- 対応要否: 今回は対応しない
- 理由: セキュリティ確認の主対象は family / plans / stock-items の主要APIであり、そちらは確認完了しているため
