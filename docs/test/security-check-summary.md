# NG / 改善余地のある項目

## 1. /api/plans/[id] の不正UUIDで500
- 確認内容: UUID形式が不正なIDを指定したときの挙動
- 実施結果: 500 Internal Server Error
- 問題内容: 入力不正であれば400 Bad Requestの方が自然
- 対応要否: 今回は対応しない
- 理由: 他人データ参照防止や削除防止などの重大論点は問題なく、MVPでは優先度を下げる
- 対応方針: 改善余地として実施記録に残す

## 2. /api/dashboard の取得経路不一致
- 確認内容: Consoleから /api/dashboard を直接叩いた時の挙動
- 実施結果: 404、ただし画面側ログではdashboardデータ取得成功
- 問題内容: 直叩きパスと実際の取得経路が一致していない可能性
- 対応要否: 今回は対応しない
- 理由: セキュリティ確認の主対象は family / plans / stock-items の主要APIであり、そちらは確認完了しているため
- 対応方針: 必要なら別途ルーティング確認タスクとして切り出す

# ■ 最終結論

主要APIにおいて、

- 認証（401）
- 認可（user_id制御）
- 入力値検証（400）

は適切に機能しており、重大なセキュリティリスクは確認されなかった。

一部、

- UUID形式不正時の500レスポンス
- API側での保存件数制御未確認
- dashboard取得経路の不一致

などの改善余地はあるが、MVPとしては許容範囲と判断した。
